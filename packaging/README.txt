SysGlance Portable (Windows x64)
================================

1. Double-click SysGlance.exe.
2. Find its icon in the Windows notification area (system tray).
3. Right-click the icon to select Desktop HUD and open Settings.

Requirements
------------

- Windows 10 version 22H2 or later, or Windows 11.
- x64 processor.
- No installer or separate VC++ runtime is required.

Notes
-----

- Settings are stored per user in %LOCALAPPDATA%\SysGlance\config.ini.
- CPU, memory and connected physical-network data should work on supported Windows.
- GPU counters depend on the graphics driver and session. In virtual machines,
  Remote Desktop sessions, or after a driver reset, GPU data can temporarily show N/A.
  This does not stop the application.
- Taskbar information bar is experimental. Desktop HUD and tray summary are recommended.
