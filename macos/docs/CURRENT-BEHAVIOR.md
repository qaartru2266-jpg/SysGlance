# 当前产品行为（SysGlance v2.0.0；Windows v1.0.3 对齐）

本文是当前已交付实现的准确信息来源；较早的 [PRODUCT-MAC.md](../PRODUCT-MAC.md) 保留为初始需求草案。

## HUD

新安装默认使用仅图标的菜单栏模式。点击“恢复推荐 HUD”后使用 360×34 pt、12 pt SF Mono、深色背景、橙色细边框；文字在面板内水平与垂直居中。已有配置不会因升级而被重置。

默认一行格式如下（GPU 采样暂不可用时显示 `G N/A`）：

```text
C05 08.0  0.1K 12.3M
```

| 槽位 | 含义 | 固定显示规则 |
| --- | --- | --- |
| `C05` | 系统整体 CPU 使用率 | 两位整数，个位补零；HUD 中 100% 显示 `99`，菜单详情保留真实值。 |
| `08.0` | 已用物理内存 GiB | 默认使用活动监视器 Memory Used 口径；可切换为两位整数百分比。 |
| `G N/A` / `G5.1/2.4` | GPU 内存 GiB / GPU 使用率 | 默认隐藏；开启后当前安全降级为 `N/A`。 |
| `0.1K` / `12.3M` | 下行与上行网络速率 | 低于 100 KiB/s 用 `K`，否则用 `M`；数值固定四字符（` 0.1` 至 `999+`）。 |

HUD 默认关闭网络上下行箭头；设置中开启后，网络段显示为 `↓ 0.1K ↑ 12.3M`。每项之间一个空格；网络完整字段固定五字符，速度与 `N/A` 状态变化不会移动后续文本。

## 交互与菜单栏

- 菜单栏仅显示系统模板图标，不显示实时数字；点击后菜单首行提供完整摘要。网络在首个有效样本前显示 `Network initializing`，没有可用接口时显示 `Network N/A`。
- HUD 未锁定且未穿透时仅可用右键拖动，位置会保存；左键和双击均无操作。
- 锁定后不可拖动；鼠标穿透会自动锁定。
- 切换至菜单栏模式时 HUD 隐藏，但采样继续进行。

## 采样与恢复

- CPU：`host_processor_info` 相邻样本差值。
- 内存：活动页、wired 页与压缩页总和；物理总内存为分母。
- 网络：聚合 `en*` 物理接口，排除 loopback、VPN 与虚拟接口。
- 首次样本、休眠唤醒、接口集合变化、计数回退或采样间隔超过三倍刷新周期后，网络显示 `N/A` 直到获得新基线。
- 显示器/缩放变化后 HUD 会约束回可见区域，并在下一次采样重新建立 CPU 与网络基线。

## 设置与版本

- 设置窗口和应用包均显示 `macOS v2.0.0`；该统一 Release 的行为基线仍是 Windows `v1.0.3`。
- 点击“应用”后，HUD 会立即使用新设置；写盘成功时会确认“设置已应用并保存”。若写盘失败，会明确提示本次运行仍已生效、重启后可能恢复旧设置。

## 已知限制

- GPU 公开稳定采样尚未完成，当前始终安全显示 `N/A`。
- 当前交付物是本地未签名 `.app`；未提供登录项、设备选择、Intel/外接 GPU 正式支持或 Dock 实验条。
