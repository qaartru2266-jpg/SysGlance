# SysGlance for macOS 产品需求文档

> 版本：0.1（历史草案）
>
> 状态：已由 Windows v1.0.1 对齐实现取代；当前行为以 `docs/CURRENT-BEHAVIOR.md` 为准。
> 对齐基准：Windows 版 [产品说明](docs/PRODUCT.md)（2026-08-12）

---

## 1. 背景与目标

SysGlance 在 Windows 上已提供稳定的桌面 HUD 与托盘摘要体验。本文件定义 **macOS 版** 的产品范围：在保持同一套信息口径与交互语义的前提下，用原生 macOS 技术实现同等能力，供个人日常使用。

**核心目标**

- 在 macOS 上提供与 Windows 版 **语义一致** 的系统状态展示（CPU、内存、GPU、网络）。
- 主体验仍是 **桌面 HUD + 菜单栏摘要**，低干扰、低常驻资源、单进程。
- 不追求与 Windows 代码共用 UI 层；**计算口径、文本格式、配置语义** 应与 Windows 版保持一致，便于跨平台对照。

**非目标**

- 不做跨平台 UI 框架（Qt / Electron / WebView）。
- 不做 iOS / iPadOS 版本（本阶段仅 macOS）。
- 不做与 Windows 版实时配置同步或云账户。

---

## 2. 产品原则

与 Windows 版保持一致：

| 原则 | 说明 |
| --- | --- |
| 原生单进程 | 使用 AppKit / Swift（或 Swift + 少量 C++ 计算层），不引入 Electron、Qt、WebView、独立后台守护进程。 |
| 采样与 UI 分离 | 后台线程（或 GCD 队列）每秒采样一次，生成 `MetricSnapshot`；UI 主线程只读快照，绘制路径不得查询系统性能接口。 |
| HUD 尺寸稳定 | 窗口尺寸由配置决定；指标刷新 **只重绘文字**，不得每秒重新定位 HUD。 |
| 失败可降级 | 单项指标失败显示 `N/A`，不影响其他指标，不导致应用退出。 |
| 文本紧凑稳定 | 固定槽位、等宽字体、尾部补位；`C` / `G` 前不加前置空格；网络单位切换不引起总宽度变化。 |
| 设置草稿语义 | 打开设置复制运行配置；预览只读草稿；“应用”才写入磁盘并更新 HUD；“取消”/关闭丢弃草稿。 |

**macOS 附加原则**

- 遵守 macOS 人机界面规范：菜单栏图标、设置窗口、辅助功能相关行为需符合 Apple 审核与系统习惯（即便首版仅自用分发）。
- 不注入 Dock、不修改系统菜单栏布局、不 hook 其他应用。
- 沙盒（若启用）下需明确权限边界；首版可优先 **非沙盒 + 签名/notarize 可选**，以降低 GPU/网络采样复杂度。

## 3. 目标平台

| 项 | 要求 |
| --- | --- |
| 系统 | macOS 13 Ventura 及以上（建议）；最低可评估 macOS 12 Monterey |
| 架构 | Apple Silicon（arm64）优先；Intel（x86_64）作为兼容目标 |
| 显示 | 支持 Retina、多显示器、刘海屏；逻辑点（pt）作为 HUD 尺寸单位 |
| 语言 | 界面与 HUD 反馈文案默认简体中文；指标缩写与 Windows 版一致 |

---

## 4. 显示模式

| 模式 | macOS 对应 | 优先级 | 说明 |
| --- | --- | --- | --- |
| 菜单栏摘要 | `NSStatusItem` | 高 | 菜单栏图标；点击/右键弹出菜单；悬停（若可实现）或菜单内展示带完整单位/百分号的摘要。 |
| 桌面 HUD | 无边框 `NSPanel` / `NSWindow` | **最高（推荐）** | 浮动层级、无焦点、严格矩形；仅右键拖动、锁定、鼠标穿透。 |
| Dock 附近信息条（实验） | 靠近 Dock 边缘的浮动条 | 低 | 类似 Windows 实验任务栏模式：仅尝试，不修改 Dock，不注入系统 UI。Notch / Stage Manager 下可能被遮挡。 |

**产品优先级**：HUD 与菜单栏摘要 > 数据可靠与可恢复 > 可配置性 > Dock 附近实验条。

默认启动模式：与 Windows v1.0.1 对齐，使用 **菜单栏摘要**；用户可在菜单或设置中切换 HUD。

## 5. 功能需求

### 5.1 指标与显示

| 指标 | HUD 展示 | 可配置项 | 与 Windows 对齐 |
| --- | --- | --- | --- |
| CPU | `C12` | 显示开关；整数或一位小数 | 系统整体 CPU，非单核、非逐进程 |
| 内存 | `08.0` 或 `45` | 显示开关；GiB 已用量 / 使用率 | 物理内存口径 |
| GPU | `G5.1/2.4` | 显示开关；GPU 内存用量 / 百分比，默认隐藏 | 文案为「GPU 内存」，不称「独立显存」 |
| 网络 | `0.1M  0.0K` | 显示开关；箭头可隐藏 | 字节/秒；HUD 省略 `/s` 和 `B` |

**HUD 文本示例**

```text
C12 08.0 0.1M  0.0K
```

**网络速率格式（必须与 Windows 版一致）**

- 不使用原始字节 `B`。
- `< 100 KiB/s`：一位小数 K（含 `0.0K`）。
- `≥ 100 KiB/s`：M（约 `0.1M` 起）。
- 每个网络字段固定 5 字符：4 字符数值槽位加 1 字符数量级；`N/A` 也使用同样宽度。

**菜单栏 / 悬停摘要**

- 可使用完整单位与百分号，例如：`CPU 12.4% | Memory 8.0 GiB (45.0%) | GPU 5.1% | Down 0.1 MB/s, Up 0.0 KB/s`。
- 与活动监视器对照网络时需说明：活动监视器常用 MB/s 或 Mbps，口径换算与 Windows 版 README 相同。

### 5.2 HUD 交互

| 交互 | 行为 |
| --- | --- |
| 拖动 | 未锁定且未穿透时，仅右键拖动 HUD 整体；位置持久化。 |
| 锁定 | 锁定后不可拖动；与穿透互斥逻辑同 Windows。 |
| 鼠标穿透 | HUD 不接收鼠标事件；通常同时视为锁定。 |
| 左键/双击 | 不响应。 |

### 5.3 设置

设置窗口为独立面板（推荐 `NSWindow` + 表单布局），包含：

**显示**

- 显示模式：菜单栏 / HUD / 实验 Dock 条
- 刷新间隔：500 ms / 1000 ms / 2000 ms
- 各指标显示开关
- 内存显示模式：已用 GiB / 使用率
- GPU 内存显示模式：已用 GiB / 使用率
- 百分比精度：一位小数 / 整数
- 网络箭头显示开关

**设备选择**

- 网络接口：默认聚合所有符合条件的物理接口；可选单一接口；可选包含 VPN/虚拟接口（默认排除）。
- GPU：默认聚合；可选单一 GPU（按唯一标识，见 §7）。

**HUD 外观**

- 宽、高（逻辑 pt）
- 字体大小
- 边框粗细、边框颜色、文字颜色、背景颜色
- 内容透明度（0–100%）
- 颜色预设（至少 3 套，语义对齐 Windows）
- HUD 预览（Owner-draw 或 SwiftUI/AppKit 内嵌预览区）

**行为**

- 锁定 HUD
- 鼠标穿透
- 登录时打开（macOS 登录项 / `SMAppService`）

**恢复**

- 「恢复推荐 HUD」：360×34 pt、字体 12、0.5 pt 橙色边框、90% 内容透明度、深色背景、未锁定。
- 「恢复上次可用布局」：最近一次成功应用且 HUD 可完整渲染时的布局。

**草稿规则**

- 控件修改、取色只更新内存草稿。
- 预览读取草稿，不移动真实 HUD。
- 「应用」：规范化 → 写配置 → 更新 MetricService 参数 → 刷新 HUD/菜单栏 → 保存 LastGood。
- 「取消」/关闭：丢弃草稿。

### 5.4 菜单栏

- 提供 `NSStatusItem` 图标（模板图，适配浅色/深色菜单栏）。
- 菜单项至少包含：显示模式切换、打开设置、退出。
- 退出前保存 HUD 位置与必要状态。

## 6. 配置持久化

| 项 | 说明 |
| --- | --- |
| 路径 | `~/Library/Application Support/SysGlance/config.ini`（推荐 INI 或与 Windows 同结构的 plist；首版需选定一种并文档化） |
| LastGood | 独立 section：`HUDLastGood`，保存上次可渲染布局 |
| 规范化 | 加载与应用后统一校验：刷新间隔、互斥项（锁定/穿透）、尺寸范围、颜色与透明度 |
| 迁移 | 不要求与 Windows 配置文件自动合并；字段命名保持一致，便于手工对照 |

## 7. 数据来源与 macOS 实现建议

> 实现阶段可调整具体 API，但 **对外语义** 必须与下表一致。

| 指标 | 建议来源 | 降级与边界 |
| --- | --- | --- |
| CPU | `host_processor_info` / `host_statistics` 相邻采样差值 | 首次为基线；仅系统整体 CPU |
| 内存 | `host_statistics64`（`HOST_VM_INFO64`） | 物理内存已用 / 总量；失败 `N/A` |
| GPU 利用率 | IOReport / `IOGPU` 相关统计，或 Metal 系统接口（需 PoC 验证） | 多 GPU 默认聚合；Apple Silicon + 外接 GPU 需实测；失败 `N/A` 并尝试重建采样 |
| GPU 内存 | 与 GPU 利用率同源或 `ioreg`/驱动报告 | 可能含共享内存；文案统一「GPU 内存」 |
| 网络 | `getifaddrs` / `sysctl` 路由与接口计数 | 默认聚合已连接物理接口；切换接口重置基线；首周期 `N/A` |

**与 Windows 一致的行为**

- 网络：切换接口、接口消失、采样间隔 > 3×刷新周期（睡眠/唤醒）→ 重置基线，首周期 `networkReady = false`。
- GPU：连续采样失败 → 重建查询，首周期 `N/A`。
- 设备消失 → 回退默认聚合（标识 `0`），不保留过期值。

**GPU 为 macOS 最高风险项**：须在 M 系列、Intel Mac、外接 GPU、远程桌面场景做 PoC；PRD 允许首版在部分机器上 GPU 长期 `N/A`，但不得崩溃。

## 8. 架构要求（实现指导）

### 8.1 推荐技术栈

| 层 | 建议 |
| --- | --- |
| 语言 | Swift 5.9+ |
| UI | AppKit（HUD、设置、菜单栏）；不强制 SwiftUI 全栈 |
| 计算/format | 可抽离为 Swift 或 C++ 模块，与 Windows `common.h` 中格式化规则对齐 |
| 并发 | 专用采样队列 + 主线程 UI；快照使用线程安全只读结构 |
| 构建 | Xcode 工程或 CMake + Swift（二选一，文档化） |

### 8.2 模块划分（概念对齐 Windows）

| 模块 | 职责 |
| --- | --- |
| `MetricSnapshot` / `AppConfig` | 共享类型与格式化辅助 |
| `MetricService` | 采样线程、设备枚举、基线重置 |
| `ConfigService` | 加载、保存、规范化、LastGood、登录项 |
| `AppUi` | 菜单栏、HUD、设置、预览、绘制 |

### 8.3 HUD 窗口

- 使用 `NSPanel`，`level = .floating` 或 `.statusBar`，`collectionBehavior` 含多 Space 可见（可配置）。
- `ignoresMouseEvents = true` 实现穿透。
- 边框与内容透明度分离（同 Windows 双表面思路，可用一层 border + 一层 content）。
- 布局入口单一：`calculateHudLayout` → `positionHudSurface`；DPI/缩放变化、显示器变更、恢复布局均走同一路径。

### 8.4 字体

- 等宽：优先 `SF Mono` 或 `Menlo`；与 Consolas 类似，保证 tabular 数字。
- 禁止为实时读数动态测量并撑开窗口。

## 9. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 空闲时 CPU 占用可忽略；内存常驻目标 < 50 MB（参考，非硬限） |
| 稳定 | 7×24 菜单栏常驻不泄漏；睡眠唤醒后 1–2 个采样周期内恢复或显示 `N/A` |
| 权限 | 网络与 CPU/内存无需特殊权限；GPU 若需隐私描述，在 `Info.plist` 说明 |
| 测试 | 格式化与边界逻辑需单元测试（XCTest）；采样与 UI 手工验证清单见 §11 |
| 无障碍 | 设置控件需基本键盘可达；HUD 为装饰性只读信息，可不强制 VoiceOver 朗读每秒数值 |

## 10. 明确不做（首版）

- 逐进程 CPU/GPU/网络排行
- 温度、功耗、风扇、频率
- 告警、通知中心推送、报表、云同步、插件、内置自动更新
- 修改系统菜单栏、Dock 或第三方应用注入
- iCloud 同步配置
- 与 Windows 版二进制共用 UI 代码

## 11. 验收标准

### 11.1 功能

- [ ] 菜单栏图标与菜单可用；可切换三种显示模式（含实验 Dock 条）
- [ ] HUD 显示 CPU/内存/GPU/网络，格式与 §5.1 一致
- [ ] 仅右键拖动；左键/双击无操作；锁定和鼠标穿透行为正确
- [ ] 设置草稿：取消不改变运行 HUD；应用后持久化并重启恢复
- [ ] 恢复推荐 HUD / 上次可用布局有效
- [ ] 网卡/GPU 选择与聚合回退正确
- [ ] 睡眠唤醒、接口切换后网络不出现错误尖峰（首周期 `N/A` 可接受）

### 11.2 平台

- [ ] Apple Silicon 实机验证通过
- [ ] Intel Mac 或 Rosetta 环境验证（若支持）
- [ ] Retina 125%/150% 缩放 + 双显示器
- [ ] 浅色/深色菜单栏下图标可见

### 11.3 测试

- [ ] 单元测试覆盖：`FormatNetworkRate`、字节速率计算、配置规范化
- [ ] 无采样失败时的崩溃或卡死

## 13. 与 Windows 版差异摘要

| 项 | Windows | macOS |
| --- | --- | --- |
| 托盘 | 通知区图标 | 菜单栏 `NSStatusItem` |
| 实验条 | 任务栏附近 | Dock 附近（可选） |
| 配置路径 | `%LOCALAPPDATA%\SysGlance\config.ini` | `~/Library/Application Support/SysGlance/` |
| 自启动 | 注册表 Run | 登录项 / `SMAppService` |
| 渲染 | Direct2D/DirectWrite | AppKit / Core Text |
| GPU 采样 | PDH + DXGI LUID | IOReport / GPU 驱动接口（待 PoC） |
| 尺寸单位 | 逻辑像素（DPI 感知） | 逻辑点（Retina 感知） |

**应保持一致**：HUD 字符串格式、网络 K/M 规则、设置草稿语义、指标含义、默认聚合策略、`N/A` 降级策略。
