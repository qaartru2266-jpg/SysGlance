# SysGlance 跨电脑测试说明

这份说明用于在另一台 Windows 电脑上验证便携版 SysGlance。测试目标不是要求所有指标都必须有数据，而是确认程序在不同 CPU、GPU、网卡和显示环境下能稳定运行、正确降级。

## 下载与启动

1. 在本仓库的 **Releases** 页面下载最新的 `SysGlance-*-win-x64.zip`。
2. 解压到任意普通文件夹，例如桌面或下载目录；不要直接在 zip 内运行。
3. 双击 `SysGlance.exe`。
4. 在 Windows 右下角通知区域找到 SysGlance 图标，右键选择“桌面 HUD”。

要求：Windows 10 22H2 或更高版本 / Windows 11，x64。便携包不需要安装器，也不需要额外安装 VC++ 运行库。

## 必测项目

### 基础运行

- 能否正常启动，托盘是否出现图标。
- 能否显示/隐藏桌面 HUD。
- HUD 是否只能通过右键拖动；左键点击和双击应无操作；锁定、鼠标穿透时不应抢占鼠标。
- 打开设置、修改一项内容后点击“取消”，实际 HUD 是否保持不变；点击“应用”后是否立即生效。
- 在 125%、150%、200% 或更高显示缩放下，确认设置窗口底部“应用 / 取消”可见；若窗口高度不足，确认右侧滚动条和鼠标滚轮可滚动到它们。
- 让下载或上传从低速升到较高速（例如 9.9K → 10.0K → 99.9K，或 K → M），确认 HUD 外框宽度、居中位置及下载/上传列位置不跳动。

### 指标与不同硬件

- CPU：启动一段有负载的程序后，读数是否合理变化。
- 内存：打开/关闭明显占内存的程序后，读数是否变化。
- 网络：进行下载或网页视频播放时，下载速率是否变化；如有上传任务，上传速率是否变化。
- GPU：运行游戏、浏览器视频或 GPU 负载程序后，观察 GPU 利用率和 GPU 内存。

GPU 在虚拟机、远程桌面、旧驱动或某些显卡驱动环境中允许显示 `N/A`；这是可接受的降级。不可接受的是程序崩溃、HUD 消失后无法恢复、CPU/内存/网络也同时停止更新。

### 恢复与兼容性

- 若有多显示器，移动 HUD 到另一块屏幕，确认位置合理且不会跑到屏幕外。
- 让电脑睡眠后再唤醒，确认程序仍在运行，网络短暂 `N/A` 后能恢复。
- 断开/重连网络，确认速率不会出现明显的虚假尖峰。
- 若选择了单个网卡，再断开该网卡，确认程序会自动回到默认聚合；首个恢复周期可短暂显示 `N/A`，随后应恢复速率。
- 如方便，尝试一次 RDP 或外接显示器后恢复，记录 GPU 是否变为 `N/A` 以及应用是否仍可正常使用。

## 反馈时请附上

- 问题发生前后的截图，尽量包含完整 HUD。
- 发生时间和操作步骤。
- 如果读数异常，说明用于对照的软件（例如任务管理器）和它显示的单位。
- 不要上传个人网络地址、账号信息或完整配置文件；如确有必要，可先删除敏感内容。
