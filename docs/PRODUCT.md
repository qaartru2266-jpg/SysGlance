# SysGlance 产品说明

## 定位

SysGlance 是一个自用优先的 Windows 轻量系统状态工具。它的核心体验是在桌面上提供一个小而稳定的 HUD，快速看清系统负载，而不干扰当前工作流。

产品优先级为：HUD 与托盘摘要 > 数据可靠与可恢复 > 可配置性 > 任务栏附近信息条。任务栏模式是实验功能，不作为主体验继续投入。

## 产品原则

- 原生 C++ / Win32，单进程，不依赖 Qt、Electron、WebView 或后台服务。
- 采样默认每秒一次；UI 只消费快照，绝不在绘制时查询性能接口。
- HUD 的窗口尺寸由配置决定，指标刷新只重绘文字，不重新定位 HUD。
- 小尺寸必须允许保留，但设置页明确提示内容可能裁切，并提供恢复入口。
- 单项采样失败显示 `N/A`，不能影响其他指标或导致程序退出。
- 数字格式保持紧凑、稳定：数值和网络单位使用固定槽位；CPU/GPU 标识不出现前置补空格。

## 显示模式

| 模式 | 适用场景 | 说明 |
| --- | --- | --- |
| 托盘摘要 | 最低干扰 | 右键菜单用于模式切换和设置；悬停显示带完整单位和百分号的摘要。 |
| 桌面 HUD | 推荐 | 顶层、无焦点、严格矩形。可拖动、锁定、鼠标穿透、双击网络精简。 |
| 任务栏附近信息条（实验） | 临时尝试 | 无边框窗口靠近任务栏，不修改 Windows 任务栏，可能被其他窗口或布局挤压。 |

## HUD 文本口径

HUD 为紧凑模式，省略冗余单位和百分号。示例：`C12.4  8.0  G5.1/2.4  ↓  0.1M   ↑  0.0K`。

| 片段 | 含义 | 可配置项 |
| --- | --- | --- |
| `C09.0` | 系统整体 CPU 使用率 | 显示开关；整数或一位小数。HUD 不显示 `%`，一位数以 `0` 补齐，避免 `C9` 到 `C11` 推动后续文字。 |
| `8.0` | 已用物理内存，单位为 GiB 但 HUD 省略单位 | 显示开关；可改为内存使用率。 |
| `G5.1/2.4` | GPU 利用率 / GPU 内存已用量 | 显示开关；GPU 内存可改为百分比。 |
| `↓  0.1M   ↑  0.0K` | 下载 / 上传速率 | 显示开关；箭头可隐藏；数值按字节每秒采样，HUD 省略 `/s` 和字节单位 `B`。 |

网络只显示数量级 `K` / `M`，不显示原始字节或字节后缀 `B`。低于 100 KiB/s 用一位小数 K（含 `0.0K`）；达到或超过 100 KiB/s 改用 M（约 `0.1M` 起）。数值槽位固定为 4 个字符，数量级槽位固定为 1 个字符，因此数量级切换不会令 HUD 内容整体伸缩。内存和 GPU 内存实际值最多显示两位整数；超过时显示 `99+` 以保持紧凑。

内存显示会在数值本身补齐宽度：整数百分比为 `08` / `84`，小数百分比或实际用量为 `08.4` / `84.0`。因此内存后只保留一个分隔空格给网络，不会因字段尾部空白而拉开距离。

双击 HUD 会切换“仅网络”模式。HUD 会短暂显示“网络精简”或“完整显示”作为反馈；锁定或鼠标穿透时不响应双击。

## 设置与恢复

设置窗口使用草稿配置：打开设置时复制当前运行配置，预览只读取草稿；“应用”才保存配置并更新 HUD；“取消”、关闭按钮和窗口关闭均丢弃草稿。

预览使用同一套 HUD 格式化、显示项、字体、边框、颜色和尺寸配置。它用于发现裁切和样式问题，但不移动或修改实际 HUD。

- “恢复推荐 HUD”重设 HUD 外观与交互为推荐值：360×34 逻辑像素、字体 12、0.5 逻辑像素橙色边框、90% 内容透明度、深色背景、未锁定。
- “恢复上次可用布局”读取最近一次成功应用且 HUD 有足够文本绘制空间时保存的布局。
- 尺寸单位均为逻辑像素，会随显示器 DPI 缩放。

## 数据来源与降级

| 指标 | 来源 | 降级与边界 |
| --- | --- | --- |
| CPU | `GetSystemTimes` 相邻采样差值 | 首次样本为基线。仅显示系统整体 CPU。 |
| 内存 | `GlobalMemoryStatusEx` | 显示物理内存已用量或使用率。 |
| GPU 利用率 | `GPU Engine` PDH 性能计数器 | 默认聚合；可按 DXGI 适配器 LUID 筛选。RDP、虚拟机、旧驱动或驱动重启后可暂时为 `N/A`。 |
| GPU 内存 | `GPU Adapter Memory` PDH 计数器 | 文案始终为“GPU 内存”，可能包含共享内存，不等同厂商软件中的独立显存。 |
| 网络 | `GetIfTable2` 接口累计字节数 | 默认聚合已连接物理接口；可选单卡，VPN/虚拟接口默认排除。 |

切换网卡或网络接口状态明显变化时，网络基线会重置；第一个周期显示 `N/A`。如果采样间隔超过当前刷新周期的三倍，也会重置以避免睡眠/唤醒后的失真速率。GPU 性能计数器连续失败时会自动重新建立查询，重建首周期显示 `N/A`。

默认聚合所有 GPU 以及所有已连接物理网卡。所选网卡或 GPU 消失时，程序退回默认聚合，不保留过期数值。

## 当前不做

- 逐进程 CPU/GPU/网络排行。
- 温度、功耗、风扇、频率。
- 告警、通知、报表、云同步、插件、自动更新。
- Explorer 注入或真正的任务栏内部扩展。
